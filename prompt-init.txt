## Direction artistique  
  
Créer un portfolio développeur inspiré de l'esthétique du background dynamique de la PS4, sans copier son interface ni ses éléments propriétaires.  
  
Le rendu doit être :  
  
* sombre ;  
* minimaliste ;  
* futuriste ;  
* premium ;  
* fluide ;  
* professionnel.  
  
Palette principale :  
  
* `#07070F` — background  
* `#2363EB` — bleu électrique  
* `#06B6D4` — cyan  
* `#34D399` — vert émeraude  
  
Le fond doit rester majoritairement `#07070F`. Utiliser les trois autres couleurs dans les gradients, glow et accents. Éviter les autres couleurs dominantes.

À droite, prévoir des icônes pour :  
  
* recherche ;

* heure actuelle.

## Background dynamique  
  
C'est l'élément visuel principal.  
  
Reproduire les grandes vagues/rubans lumineux visibles dans l'image avec du **SVG, CSS et/ou Canvas**.  
  
Créer plusieurs rubans fluides :  
  
* bleu `#2363EB` dominant ;  
* cyan `#06B6D4` ;  
* vert `#34D399`.  
  
Ils doivent être larges, translucides, organiques et avoir une largeur variable.  
  
Ajouter :  
  
* gradients ;  
* plusieurs couches ;  
* transparence ;  
* blur ;  
* glow ;  
* superposition ;  
* profondeur ;  
* luminosité renforcée aux croisements.  
  
Les rubans doivent ressembler à des vagues de lumière flottant dans un espace sombre, et non à de simples lignes.  
  
## Animation  
  
Le background doit être continuellement animé mais très lentement.  
  
Les rubans doivent légèrement :  
  
* onduler ;  
* se déplacer ;  
* modifier leur courbure ;  
* changer leur luminosité.  
  
Le mouvement doit être organique, fluide et presque imperceptible.  
  
Ne pas utiliser d'animations rapides ou flashy.  
  
## Interaction du curseur  
  
Ajouter un petit halo radial autour du curseur, principalement en `#06B6D4`.  
  
Le curseur peut influencer très légèrement les éléments proches :  
  
* glow ;  
* particules ;  
* position des rubans ;  
* luminosité.  
  
L'effet doit être subtil et revenir progressivement à son état normal.  
  
Les éléments interactifs doivent également avoir un effet `hover` fluide de **200–400 ms**.  
  
## Responsive  
  
Conserver cette composition sur desktop.  
  
Sur tablette et mobile :  
  
* adapter le menu ;  
* réduire les éléments décoratifs si nécessaire ;  
* conserver les grandes vagues ;  
* garder le hero lisible ;  
* transformer le menu latéral en navigation adaptée au mobile.  
  
## Performance  
  
Le background doit être réellement généré par le navigateur et rester performant.  
  
Privilégier :  
  
* SVG/CSS ;  
* `transform` ;  
* `opacity` ;  
* `requestAnimationFrame` si nécessaire ;  
* événements `pointermove` optimisés ;  
* GPU acceleration.
